# 资产图提示词创作（画面与画风）

## 输入变量

输入来自开头 JSON 数据块：`assets` 只包含本次拆解新建的画布节点，含真实 `node_id`。资产字段可能直接位于每条对象上，也可能位于 `asset` 子对象中，例如 `{"node_id":"n_1","asset":{"type":"character","name":"林川","look":"童年","description":"短发少年","voice_prompt":"清亮声线","episodes":[1],"aliases":[]}}`。`style` 是项目画风的正向描述，`genre` 是题材；`characters_md` 与 `episodes` 可作为连续性背景。`validation_error` 为上次输出的校验反馈。

## 本步职责

本步骤为每个新资产写一段可直接用于图片生成的画面描述。下一步会把每段描述和它的节点编号整理成标准的提示词条目，所以这里只写画面，不写编号和格式。

## 提示词正文

为每个新资产写一段中文正向提示词。不要为已有资产或未给出的节点写内容。

先保持资产的名称、造型和描述的视觉身份，再融入项目画风的材质、线条、光照、色彩和时代感。画风是整部作品的统一视觉约束，不能在不同资产之间任意改换。优先写出可见、具体、稳定的外貌和环境特征，避免把音色、剧情梗概或抽象情绪当成外观。每段用一段连贯的中文描述，按「主体、构图、细节、背景与光线、画风」的顺序组织，每段信息具体到可以直接绘制，不用「好看」「有气质」这类空泛词。

### 角色：四视图设定图

- 构图：四画面不对称分栏构图：左侧约占40%宽度，为胸部以上的正面平视特写大图，平视高度，完整展示面部五官、表情；右侧约占60%宽度，排列同一角色的三个完整全身视图，从左到右依次为正面、严格90度侧面、背面。所有全身人物保持等比例、等高度，脚底对齐同一水平线，间距均匀，头到脚完整入画，且所有视角的发型、服装和配饰完全一致。
- 人物细节：写清性别与年龄段、身高体型、脸型与五官特征、发型发色与长度、肤色、气质，以及服装每一层的款式、颜色、材质、纹样，鞋履和配饰（首饰、腰带、背包、眼镜、疤痕、纹身等）。强调面部和服装在各个视图下都清晰可辨，背面要交代发型后部和衣服背部结构。
- 未成年角色（儿童、少年）：按常规的儿童服装设定图来写，只写年龄段、身高体型、发型、服装配饰、站姿和神情；不描写皮肤质感、嘴唇、身材曲线等身体细节，不用「白嫩」「水润」「红润」「娇嫩」这类形容，服装完整得体，不写暴露或贴身的穿着。
- 背景与光线：纯净的浅灰或纯白背景，无场景、无地面杂物，柔和均匀的一致照明，无强烈投影，便于后续镜头保持身份一致。
- 如果该角色有多个造型，只画当前造型，不要混入其他造型的元素。

### 场景：空间格局图

- 构图：以主视角呈现整个空间的格局，可辅以同一空间的另一角度（如反向或俯视），交代门窗、通道、主要陈设之间的相对位置，近景、中景、远景层次分明，保证后续镜头能找到方位。
- 内容：写清室内或室外、时代与地域风格、建筑结构与规模、关键陈设和标志性物件的位置、材质与主色调、墙面地面质感与使用痕迹。
- 光线：明确时间段、天气、主要光源（自然光方向、灯具类型）、光色与氛围，保持与项目画风一致。
- 画面中不出现人物、动物剪影和文字标识，保持空间干净，只呈现环境本身。

### 道具：产品参考图

- 构图：道具居中，清晰展示整体外形，可并列正面与侧面或 45 度角及一个关键细节特写，同一个道具外观完全一致；单个道具独立呈现，不出现人物、手或肢体，不手持展示。
- 内容：写准确的形状与比例（可说明相当于手掌或成人手臂的大小作比例参照）、材质、颜色、表面纹理、磨损或做旧程度、刻字花纹等关键辨识特征，以及结构部件。
- 背景与光线：干净的纯色或浅灰背景，柔和的产品摄影式布光，边缘清晰，投影轻微。

提示词只描述要生成的正向画面，不添加 UI 标签、水印、对话字幕、无关角色或与既有造型冲突的设计。人物名称用于标识一致性，不能代替具体外观。画面比例、横版竖版、尺寸和分辨率由图片节点的生成参数控制，描述里不写。

## 输出约定

只输出纯文本。每个新资产单独成段，段首写出它的节点编号和一个冒号（如 `n_1：`），节点编号必须与输入完全一致，每个节点恰好一段。不输出 JSON、代码围栏、标题或解释。

## 校验规则

- 每个输入的新节点恰好一段，不漏项、不重复、不编造节点编号。
- 每段都是非空的画面描述，与资产类型、造型和统一画风一致。
- 描述只包含画面本身，不添加 UI 标签、水印或字幕。
